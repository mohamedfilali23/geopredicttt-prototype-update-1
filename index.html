Eurocode 7 Compliant

Automatic calculation of bearing capacity factors Nq, Nc, Nγ and shape factors according to EC7 — the European reference standard in geotechnics.

3-Stage ML Pipeline

Three-stage Random Forest architecture: bearing factors (R²≈0.96), ultimate/allowable capacity (R²≈0.96), and safety factor (R²≈0.92).

Groundwater Management

Methodology

Prediction Model
Architecture

A 3-stage Random Forest pipeline, trained on 5,000 synthetic cases generated using real geotechnical parameter distributions.

3-Stage Random Forest Pipeline

1
RF Stage 1
Multi-output RF predicts the 6 EC7 bearing and shape factors from soil + foundation inputs.
NqNcNγsqscsγ
2
RF Stage 2a
Uses Stage 1 predicted factors + all input parameters to compute bearing capacities.
qu (kPa)q_adm (kPa)
3
RF Stage 2b
Directly learns FS = qu / q_app from predicted qu and applied load.
FS

Cas 0
No Influence
Zw ≥ Df + B
Rw1 = 1.0 | Rw2 = 1.0
γeff = γ
Cas 1
Above Foundation
Zw ≤ Df
Rw1 = 0.5(1 + Zw/Df)
Rw2 = 0.5 | γeff = γsat
Cas 2
In Influence Zone B
Df < Zw < Df+B
Rw1 = 1.0
Rw2 = 0.5(1 + zw2/B)
